Demonlist Visualization Tool

Tags, difficulty and enjoyment across the AREDL. All data for this project was gotten using the AREDL api so go support them. The color palette for this project was generated using coolors.co.

Tags vs difficulty

Share of levels in each position bucket that carry each tag. Rows are sorted by how high on the list the tag tends to appear.

If you change the levels per column to something other than 150 note that the last bucket will contain considerably fewer levels than the other buckets and thus the percentage will be higher even if the bucket contains the same amount of levels as another bucket. TLDR: I reccomend keeping it at 150 levels per column.
(this might change in the future as more levels get added)

Tags vs enjoyment

Average EDEL rating of the levels with each tag, shown as the difference from the average across all rated levels. Orange means a tag's levels are rated more enjoyable than average, blue means less. The number in brackets is how many rated levels the tag has.

Level similarity

Every dot is a level. Levels that share a lot of tags are pulled together, so clusters are groups of levels that play alike. Color shows difficulty: amber is near the top of the list, blue is near the bottom. Toggle tag groups to change what "similar" means, for example tick version and watch the clusters turn into noise.

Top creators by enjoyment

Creators ranked by the average EDEL enjoyment of their levels on the list. The number in brackets is how many rated levels they have. "Creator" means whoever published the level in game, so a collab is credited to its host. The axis doesn't start at zero, so compare dots by position and not by distance from the left. A creator with 3 levels is a much shakier average than one with 10, so raise the minimum for more reliable results.
